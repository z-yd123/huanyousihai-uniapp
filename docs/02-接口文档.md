# 接口文档

服务端模块：`ruoyi-hys`（挂载在 `ruoyi-admin` 内，随框架一起启动，默认 `http://localhost:8080`）。
共 **63 个接口**：小程序端 32 个（`/app/**`）、管理端 31 个（`/hys/**`）。

## 通用约定

| 项 | 说明 |
| --- | --- |
| 响应体 | `AjaxResult { code, msg, data }`；分页为 `TableDataInfo { code, msg, rows, total }` |
| 状态码 | 框架的 `HttpStatusResponseAdvice` 会把业务异常翻译成真实 HTTP 状态（400 参数错、401 未登录、403 无权限、500 业务异常） |
| 金额 | 全部为「分」（`BIGINT`/`Long`），字段名带 `amount` / `price` / `balance` 的均为分 |
| 时间 | `LocalDateTime` 序列化为 `yyyy-MM-dd HH:mm:ss`，`LocalDate` 为 `yyyy-MM-dd` |
| 小程序鉴权 | 请求头 `Authorization: Bearer <token>`，令牌由 `/app/auth/login` 或 `/app/auth/register` 下发 |
| 管理端鉴权 | 框架自带 `Authorization: Bearer <adminToken>`，由 `@PreAuthorize("@ss.hasPermi('...')")` 控制 |

## 一、小程序端（`/app/**`）

### 1. 账号 `HysAppAuthController`

| 方法 | 路径 | 说明 | 请求体 / 参数 | 返回 |
| --- | --- | --- | --- | --- |
| POST | `/app/auth/register` | 注册（推荐人码必填） | `{referrerCode, nickname, phone, password, province, city, district}` | `{token, member}` |
| POST | `/app/auth/login` | 登录 | `{phone, password}` | `{token, member}` |
| POST | `/app/auth/logout` | 登出（`token_version` +1，旧令牌全部失效） | — | — |
| POST | `/app/auth/password` | 修改密码（成功后必须重新登录） | `{oldPassword, newPassword}` | — |
| POST | `/app/auth/forgot` | 找回密码（手机号 + 注册名称双核验） | `{phone, nickname, newPassword}` | — |

> 以上 5 个接口均为 `@Anonymous`（不校验令牌）；`logout` / `password` / `forgot` 的业务身份从令牌或请求体推导。

> 全部接口都需要 `Authorization`（管理员令牌）且通过 `@PreAuthorize` 权限码校验。

### 8. 业务参数

| 方法 | 路径 | 权限码 | 说明 |
| --- | --- | --- | --- |
| GET | `/hys/config/list` | `hys:config:list` | 全量参数（17 项） |
| PUT | `/hys/config` | `hys:config:edit` | `{configKey, configValue}`；服务端 `validate` 强制合规红线 |

**服务端强制校验的红线**（改错会直接返回 500 并给出原因）：

- `payout.total` 必须等于 `20000`；`payout.direct_first_two + payout.indirect_first_two` 必须等于 `20000`
- `payout.max_depth` 不允许修改（层级固定两级）
- `payout.withdraw_fee_rate` 必须在 `[0, 0.06]`
- `wallet.recharge_limit` 必须 ≤ `500000`

## 三、错误码与典型提示

| HTTP | 场景 | 提示文案（节选） |
| --- | --- | --- |
| 400 | 参数校验失败 | 「手机号格式不正确」「单笔最多 20 件」「收款账号格式不正确」 |
| 401 | 令牌缺失 / 过期 / 版本失效 | 「登录状态已失效，请重新登录」 |
| 403 | 无权限码 | 「没有权限，请联系管理员授权」 |
| 500 | 业务规则拒绝 | 「可用余额不足，当前余额 12.00 元」「今日互转次数已达上限（20 次），请明日再试」「当前订单不在售后中」「该记录已处理，请刷新」 |
