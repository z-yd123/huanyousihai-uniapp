## 三、功能规格（AGENT.md §4）

### 4.1 注册与登录

| 需求 | 实现 | 状态 |
| --- | --- | --- |
| 推荐人码必填，无邀请码不允许注册 | `Register.referrerCode @NotBlank` + 服务端校验推荐人存在且未停用 | ✅ |
| 名称 / 手机号 / 区域（省市区）/ 密码 | `Register` DTO 全覆盖，手机号 `@Pattern("^1[3-9]\\d{9}$")`，密码 6-20 位 | ✅ |
| 方式 A：手动输入推荐人手机号 | 注册页 `referrerCode` 输入框 + 实时显示推荐人姓名 | ✅ |
| 方式 B：扫码带推荐关系 | 海报页展示服务端生成的真实二维码（`/app/member/invite-qr`），扫码进入注册页自动带入 `?ref=` | 🟡 二维码内容已带邀请码；小程序码需真实 AppID，当前以二维码承载同等信息 |
| 登录 / 退出 / 改密 / 找回密码 | 4 个接口 + 4 个页面；改密/登出使 `token_version` +1，旧令牌立即失效 | ✅ |
